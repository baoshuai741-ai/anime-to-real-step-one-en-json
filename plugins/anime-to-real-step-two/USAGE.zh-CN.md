# 漫画转真人·第二步使用说明

## 与第一步交替使用

第一步和第二步是两个独立插件入口，但每一轮转换都必须按“第一步 → 第二步”交替使用。新原画、角色设计变化、多图职责变化或关键约束变化时，必须重新执行第一步并确认新的 JSON，随后才能执行第二步。不得用旧 JSON 跳过第一步，也不得把第二步的结果倒写成第一步视觉事实。

## 输入与输出

第一步只分析当前原画，并返回完整、有效的 JSON。审阅并确认 JSON 后，在新的第二步请求中同时附上同一张原画和已确认的第一步 JSON，明确要求生成第二步真人图。第二步不得从早先聊天补取图像或 JSON；任何一项缺失都需重新提供。若只要求提示词，第二步返回审核后的生成提示词，并把图像验证标为待生成。若明确要求生成，第二步输出写实真人图，并对照当前原画和 JSON 检查结果。第三步只在用户另行明确要求时开始。

## 规则优先级

1. 原画角色 DNA 锁定
2. 人物身份锁定
3. 构图／姿势锁定
4. 现实人体转译
5. 现实头发转译
6. 现实服装／材质转译
7. 物理光影锁定
8. 真实摄影成像锁定
9. Anti-AI 抑制

原画对角色DNA、身份、姿势、构图、服装及可见光影是最高视觉权威；固定 `9 head body proportion` 是用户明确指定的唯一身体比例例外。JSON 是第一步对可见事实的结构化记录；若两者冲突，保留原画并指出冲突。后层只能把前层确定的视觉信息转译为物理和摄影效果，不能改变角色、面部关系、服装、姿势、相机、背景或可见光影；身体比例仅按固定目标作必要转译。遮挡、裁切和模糊区域保持未知；仅当前请求明确指定的字段可覆盖对应字段。

目标措辞固定为 Extreme Photographic Realism + Physically Plausible Lighting + Real-Camera Imaging。二维高光、描边和色块先判断其设计含义，再转成可信的光学或材质效果；不能机械地当作染发、发光、衣物图案或第二光源。不得用 surreal 或 surrealistic 描述目标效果。高分辨率不等于过度锐化。

## 备份与恢复

如果您在本地升级前创建了备份，应先核对备份 manifest 的版本和文件，再把备份源目录恢复到您自己的插件源目录。随后使用 plugin-creator 的 cachebuster 脚本写入新缓存标识，从对应 marketplace 重新安装并核对缓存中的正式文件。保留备份本身，不在缓存目录直接编辑。恢复或升级后用新任务调用技能，以读取新的安装版本。

## 2026-09-16 固定目标更新

第一步照常记录原画可见身体比例，但在目标 `body.proportion` 写入固定的 `9 head body proportion`。第二步只对身体比例作必要的真实解剖转译；人物身份、面部关系、姿势、相机、构图、服装与原画可见光影继续锁定。面部皮肤要呈现超写实真人皮肤的区域差异与真实摄影细节，避免塑料感、均匀毛孔噪声和过度锐化，不擅自新增雀斑、疤痕或年龄痕迹。最终目标为 Extreme Photographic Realism + Physically Plausible Lighting + Real-Camera Imaging。

## 真实人体与头发动力学

所有面部表情、手势和全身动作都必须通过真实的骨骼排列、关节活动范围、主动肌与拮抗肌配合、肌腱与软组织位移、皮肤拉伸／挤压、重心、承重、接触力、惯性和次级运动成立。原画继续决定情绪、表情强度、视线、动作意图、姿势方向和剪影；若二维形状无法由真人完成，只作最小必要的生理修正，不得换成另一种表情、普通站姿或通用肢体语言。

头发必须同时保留 Hair Design DNA 并服从真实物理因果：头皮附着与发根方向、分缝和发际线、发束层级、密度、长度、质量、柔韧性和可见造型支撑，随后才是重力、人物运动产生的惯性、图中有依据的风或湿度，以及头发与脸、肩、身体、服装、饰品和其他发束之间的碰撞与摩擦。能通过真实剪裁、编扎、束发、适量造型产品或原画可见饰件成立的夸张设计应保留；无法成立时只作最小物理修正，并保留方向、体积层级、标志性发束和整体剪影。不得把角色发型普通化，也不得擅自添加风、湿发、隐藏支架、统一碎发或与镜头尺度不符的逐根锐化。
